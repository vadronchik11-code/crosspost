# Crosspost – отложенный постинг в VK и Telegram

Один пост → превью отдельно для VK и Telegram → правки под каждую площадку → подложка → отложка.

## Запуск на ПК (Windows)

1. Скопируй `.env.example` → `.env` и заполни (или просто запусти `start.bat` – он создаст `.env` и откроет его в блокноте).
2. Двойной клик по `start.bat`. Скрипт сам:
   - создаст `.venv` и поставит зависимости,
   - если задан `TG_VLESS` – скачает xray-core в папку `./xray`,
   - поднимет сервер на `http://127.0.0.1:8000` и откроет браузер.

Все данные (база, картинки, подложки) лежат в папке `data/` – её можно переносить на VPS вместе с `.env`.

## Запуск в Docker (VPS)

```bash
cp .env.example .env   # заполнить
docker compose up -d --build
```

Сайт будет на `http://<ip>:8000`. Папка `data/` монтируется в контейнер. xray-core ставится в образ автоматически.

## .env

| Переменная | Что это |
|---|---|
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | первый руковод: создаётся при первом запуске, если в базе нет пользователей. Дальше профили заводятся на сайте («Команда») |
| `VK_TOKEN` | ключ доступа сообщества с правами «Стена», «Фотографии», «Сообщения» |
| `VK_GROUP_ID` | id сообщества **без минуса** |
| `TG_BOT_TOKEN` | токен от @BotFather |
| `TG_CHAT_ID` | `@username` канала или `-100…` |
| `TG_VLESS` | `vless://…` – приложение само поднимет xray и пустит через него **только** Telegram |
| `TG_PROXY` | SOCKS5/HTTP-прокси для бота и аккаунта, напр. `socks5://127.0.0.1:10808`. Если VPN включён на всём ПК – оставь пустым |
| `TG_API_ID`, `TG_API_HASH` | аккаунт Telegram для отложки на серверах Telegram (my.telegram.org) |
| `TG_MTPROXY` | MTProto-прокси для аккаунта: `tg://proxy?server=…&port=…&secret=dd…` |

## Как получить токены

### VK

**Ключ доступа сообщества** (`VK_TOKEN`): Управление сообществом → Работа с API → Ключи доступа → права «Стена», «Фотографии». Им уходит текст (с жирным/курсивом/ссылками), правки и удаление. `VK_GROUP_ID` – число из `vk.com/club123456`, без минуса.

**Картинки – через VK-браузер.** Ключ сообщества фото прикрепить не может, поэтому пост с картинками сайт создаёт в **отложке VK** через настоящий Chromium под аккаунтом админа группы – так же, как человек на vk.com. Дальше VK публикует сам.

Подключение (один раз, на ПК):
1. `start.bat` поставит Chromium (~150 МБ) при первом запуске.
2. На сайте (руковод/тимлид) → **«VK-браузер»** → «Открыть окно входа» → в открывшемся окне войти в VK под админом группы. Окно закроется само, сессия ляжет в `data/vk_web_state.json`.
3. Для VPS скопируй `data/vk_web_state.json` в `data/` на сервере (Docker-образ уже с Chromium). «Проверить сессию» покажет, жива ли она.

Как работает: «Запланировать» → пост с фото сразу создаётся в отложке VK на твоё время (форматирование дописывается ключом через `wall.edit`); «Опубликовать» → выйдет через 2 минуты. До выхода можно править текст и время («Применить», «Перепланировать»); удаление на сайте снимает запись с отложки. Пост без картинок уходит ключом напрямую.

Если VK поменял вёрстку и шаг не прошёл – ошибка назовёт шаг, скриншоты каждого шага лежат в `data/vk_debug/` и видны в «VK-браузер → Скриншоты». На ПК можно смотреть браузер вживую: `VK_WEB_HEADED=1` в `.env`.

Риск: это личный аккаунт под автоматикой – VK может попросить капчу или ограничить аккаунт. Используй отдельный аккаунт-админ, не основной.

### Telegram: бот
1. **@BotFather** → `/newbot` → токен → `TG_BOT_TOKEN`.
2. Канал → Администраторы → добавить бота с правом «Публикация сообщений».
3. `TG_CHAT_ID`: `@имя_канала` или `-100…` (приватный: оставь пустым, напиши в канал и нажми в шапке «TG_CHAT_ID не задан – найти»).

Бот публикует сразу и правит опубликованное. Отложку боты не умеют (`SCHEDULE_BOT_NOT_ALLOWED`) – без аккаунта отложенные посты хранит и отправляет наш сервер.

### Telegram: аккаунт (отложка на серверах Telegram)
Чтобы отложка не зависела от сайта, подключается **аккаунт пользователя** – админ канала:
1. [my.telegram.org](https://my.telegram.org) → API development tools → создать приложение → `TG_API_ID`, `TG_API_HASH` в `.env`.
2. Прокси для аккаунта: `TG_MTPROXY=tg://proxy?server=…&port=…&secret=dd…` (MTProto-прокси из клиента; секрет с `ee…` не поддерживается) или `TG_PROXY=socks5://…`, или VPN на всей системе.
3. На сайте (руковод/тимлид) → **«Telegram»** в шапке → телефон → код из Telegram → пароль 2FA, если есть. Сессия хранится в `data/tg_user.session`.

Дальше «Запланировать» сразу кладёт пост в **отложенные сообщения канала** (видно в Telegram в «Отложенных») – выйдет по расписанию даже при выключенном сайте. Правки до выхода: пост пересоздаётся в отложке. После выхода сайт находит опубликованные сообщения и правит их аккаунтом. Удаление поста на сайте снимает его с отложки Telegram.

## Как работает

- Текст вставляется в общее поле (ссылки в словах, жирный и эмодзи из чата VK сохраняются; выделение – панель форматирования). Кнопки **VK** и **Telegram** под ним: серая – нажми, чтобы скопировать текст туда; зелёная «пост уйдёт» – текст есть, площадка включена; повторное нажатие очищает и выключает. Постим только туда, где есть текст.
- Картинки общие. Подложка – картинка-фон, своя у каждого поста (загружается в блоке «Подложка» для VK и/или TG, «одинаковую для обоих»); в посте идёт первой. Новый пост начинается без подложки.
- Текст правится прямо внутри превью: карточка VK и пузырь Telegram – это и есть редакторы, с реальным названием/аватаркой группы и канала.
- Кнопки: **В черновик** – просто сохранить; **Опубликовать сейчас** – в отложку через 2 минуты, поле «Когда публиковать» игнорируется; **В отложку** – на время из поля «Когда публиковать». Telegram – в отложку на серверах Telegram (аккаунт), VK – в отложку VK (VK-браузер). Пост можно открыть из списка слева и изменить до выхода.
- Если одна из площадок упала – статус «ошибка», текст ошибки виден в карточке, после правки можно отправить снова: уйдут только те площадки, где не получилось.
- Время: команда живёт в UTC+5 (Челябинск), и сайт везде показывает и принимает время в UTC+5 независимо от часового пояса сервера или телефона. Внутри всё хранится в UTC; VK-браузер работает в поясе Asia/Yekaterinburg, Telegram получает момент выхода в UTC – так что сервер в UTC+3 ничего не сдвинет.
- Telegram: подпись к фото до 1024 символов; если текст длиннее – фото уйдут первым сообщением, текст вторым (превью это показывает).
- Форматирование: выдели текст. В поле Telegram – правый клик, меню как в Telegram Desktop (жирный, курсив, подчёркнутый, зачёркнутый, цитата, моноширинный, скрытый, ссылка; горячие клавиши те же). В поле VK – всплывающая панель Ж К Ч 🔗: VK в постах умеет только это (уходит через `format_data`).

## Роли и команда

| Роль | Что может |
|---|---|
| Руковод | всё: посты, команда, назначать любые роли |
| Тимлид медиа | всё, кроме назначения/удаления руковода |
| Медиа | писать, планировать и публиковать свои посты; чужие – только просмотр |

Руковод или тимлид открывает «Команда» → создаёт профиль (ник, пароль, должность) и скидывает человеку ник и пароль. Пароль потом можно сменить в профиле или сбросить из «Команды».

У каждого поста видно, кто создал и кто последним правил; в блоке «История» – все изменения с полями, временем и автором (время везде в UTC+5, Челябинск).

## Правки опубликованного поста

Оба API умеют редактировать: Telegram – `editMessageText/Media`, VK – `wall.edit`. После сохранения правок в опубликованный пост сайт спросит «Пост изменился! Применить изменения?». Что Telegram **не** позволяет: менять количество фото в альбоме, менять тип вложения (фото ↔ файл) и переносить текст между подписью и отдельным сообщением (порог 1024 символа). В этих случаях сайт покажет ошибку – удали пост и опубликуй заново.

## Фото

Сайт хранит оригиналы байт в байт. VK и Telegram пережимают фото на своей стороне; в Telegram без сжатия можно только файлом – переключатель «Telegram: без сжатия (как файл)» в блоке «Картинки».
